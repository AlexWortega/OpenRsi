# Ramsey attack log

## Restatement

Construct, for each palette size `k`, a triangle-free edge-coloring of a complete graph on at least `k^{c k}` vertices (ideally `(c k^{1/3}/log k)^k`). Equivalently, make the number of vertices per color increase unboundedly with `k`, rather than merely obtaining a fixed-base exponential.

## Three promising routes

1. **Lexicographic/tensor composition of colorings.** Establish exact composition lemmas and search for a base object whose amplification improves vertices per color. Expected difficulty: medium for the lemmas, very high for breaking the exponential barrier.
2. **Capacity formulation with graphs of independence number two.** Find graphs `G` with `alpha(G)=2` whose strong powers have unusually *large* independence number, then translate to colorings. Expected difficulty: very high; this is the core capacity obstruction.
3. **Recursive palettes / algebraic local rules.** Color vector-space pairs using first differing blocks plus auxiliary algebraic labels, attempting to reuse colors safely across coordinates. Expected difficulty: high; naive reuse creates monochromatic triangles, but small finite searches may expose viable rules.

## Initial rigorous baseline

Binary first-difference coloring gives `R_k(3)>2^k`; see `proof_ramsey.md`.

## Completed cheap structural results

General first-difference amplification is formalized: an `r`-color seed on `q` symbols gives an `nr`-coloring on `q^n` words. Taking `q=R_r-1` recovers `R_(nr)-1 >=(R_r-1)^n`; larger alphabets help exactly when seed Ramsey bases already grow. This route is therefore circular for the superexponential target. The `K_5` seed amplified to a four-color `K_25` was exhaustively checked.


The lexicographic construction gives an `(r+s)`-color triangle-free coloring on `mn` vertices from colorings with parameters `(r,m)` and `(s,n)` (disjoint palettes). Iteration only gives fixed-base exponential; see `proof_ramsey.md`.

A small exhaustive search found the following partition of the nonzero vectors of `F_2^4` into sum-free sets:

`{1,2,4,8,15}`, `{3,5,7,10,11}`, `{6,9,12,13,14}`.

This supplies a directly checkable three-coloring of `K_16`. Search/verification script:

```python
from itertools import combinations
U=set(range(1,16))
def sf(S):
    return all((a^b) not in S for a,b in combinations(S,2))
sets=[set(c) for c in combinations(U,5) if sf(c)]
for A in sets:
    for B in sets:
        if A.isdisjoint(B):
            C=U-A-B
            if len(C)==5 and sf(C): print(A,B,C)
```

This is weaker than the known classical exponential base quoted in the prompt, so it is a verified baseline rather than research-level progress. A local-search partition of `F_2^5\{0}` into four explicit sum-free sets gives a `K_32` four-color seed; all 4,960 triangles were checked. Its parameters exactly match `K_16` lexicographically multiplied by `K_2`, so it has no numerical value; however class sizes `8,7,7,9` differ from product sizes `10,10,10,1`, making it a structurally distinct finite search benchmark. A focused local search for a four-color sum-free partition of `F_2^6\{0}` repeatedly reached one remaining monochromatic line but not zero, including an additional 111-second min-conflicts run; no `K_64` construction or impossibility is claimed. A complete backtrack shows the displayed `F_2^5` partition cannot be extended while keeping its colors fixed on the codimension-one layer (all four choices for the new layer's zero vector fail in <=64 search nodes). This rules out only that rigid extension, not other partitions. Constraint: layer-one variables `c(y)` must obey `not(c(y)=c(z)=i)` whenever `y xor z in T_i`; there are no all-layer-one projective lines because parity is odd. MRV backtracking exhausts all assignments. Run `python3 verify_ramsey.py` to reproduce the seed and nonextension checks using only the standard library. ## Capacity bridge and quantifier check

A rigorous broad obstruction strengthens the chromatic bound: fractional clique-covering gives `Theta(G)<=chi_f(overline G)<=chi(overline G)`. Thus achieved base `t^a` requires triangle-free complement fractional chromatic number at least `t^a`. Bipartite nonempty `H` gives equality `2^m`. Since the universal lower bound here is only `Theta(G)>=alpha(G)=2`, large fractional chromatic number merely opens a possible gap; it does not construct codes. A random product-word argument allowing a different symbol distribution in every coordinate yields direct first-moment geometric base at most `sqrt(2)`: Motzkin--Straus (or weight-merging) gives `q_j=2 sum_edges p_u^(j)p_v^(j)<=1/2` in each coordinate. Referee correction: this does not rule out expurgation. Elementary conflict-edge expurgation and the symmetric LLL extend to varying marginals and approach geometric base at most `(product_j(1-q_j))^(-1/m)<=2`, still no better than binary. More structured correlation/analysis is essential to exceed 2. Exhaustive LP checks for all `H` through five vertices at power two agree. Exact diagnostic LP values: `chi_f(C5)=chi_f(Petersen)=5/2`, cube `=2`, Grötzsch `=29/10`, Hoffman--Singleton `=10/3`.


The translation is now proved in both directions and yields the exact identity `max_(alpha(G)<=2) alpha(G^boxtimes k)=R_k(3)-1`. A maximizer can be chosen on `k(R_k-1)` vertices, hence below `3k*k!` using the classical upper bound. The same proof generalizes exactly: `max_(alpha(G)<=r) alpha(G^boxtimes k)=R_k(r+1)-1` for diagonal clique Ramsey numbers. Thus allowing an arbitrary graph depending on `k` is literally the original problem; capacity language helps only with coherent families/fixed graphs/effective power control. For `alpha(G)<=2`, an independent set in `G^boxtimes m` gives an `m`-color triangle-free complete-graph coloring by the first coordinate containing a distinct nonedge. Hence `R_m(3)>alpha(G^boxtimes m)`. Random small-graph bridge tests passed. A fixed graph with capacity `Theta(G)` gives bases arbitrarily close to `Theta(G)` on infinitely many multiples of one power. Unbounded capacities therefore give unbounded bases along graph-dependent arithmetic progressions, but without uniform control of the required power they do not automatically imply a rate `k^(ck)` for every `k`. This quantifier issue is now explicit in `proof_ramsey.md`. The bridge was checked on the standard size-5 independent set in `C_5^boxtimes2`. An exact maximum-clique search over complements of all labeled triangle-free graphs through 6 vertices (and NetworkX atlas unlabeled graphs through 7) found max strong-square independence 4 for graph order <=4 and 5 for orders 5--7, attained by the `C_5` complement example. This is finite computational evidence only. Random greedy scans over maximal-style triangle-free complements on 8, 10, and 12 vertices, the Petersen, cube, Hoffman--Singleton, and first two nontrivial Mycielski extensions of `C_5` found no major improvement. The 11-vertex Mycielski (Grötzsch) graph has exact power-two maximum 5; it produced a power-three greedy code of size 11 (base `11^(1/3)≈2.224`, still below `sqrt5`); all power-two scans stayed at 5. This is heuristic evidence only. Disjoint unions and independent-vertex blowups of `C_5` likewise stayed at code size 5 in power two under greedy search; these graph enlargements add no evident capacity leverage. The power-two picture is now complete. For every `alpha(G)<=2`, `alpha(G^boxtimes2)<=5` by translating six codewords to a forbidden triangle-free red/blue coloring of `K_6`. The possible values are `1,4,5`; equality 5 holds iff triangle-free `H=overline G` contains a `C_5` subgraph. A code gives a red/blue triangle-free coloring of `K_5`; both colors are cycles, and one coordinate cycle maps injectively into `H`. Hence every `C_5`-free triangle-free complement with an edge has exact power-two code size four; all odd cycles of length >=7 are covered. This does not imply capacity two: higher powers may improve because independence is supermultiplicative. Only bipartite complements are controlled at every power. Exhaustive atlas checks through 7 vertices agree. The universal identity gives strong-cube maximum `R_3(3)-1=16`; for `alpha(G)=2` values lie in `[8,16]`. Exact atlas computations through graph order five show only 8 and 10 (plus 1 for complete graphs). For `C_5` at power three, an exact 125-vertex compatibility maximum-clique computation gives independence 10, base `10^(1/3)<sqrt(5)`, so power two is the better witness. Conversely, any triangle-free `k`-coloring on `N` vertices gives a graph `G` with `alpha(G)<=2`, `|V(G)|=kN`, and `alpha(G^boxtimes k)>=N`: take the join of the complements of the individual color graphs and diagonally encode each original vertex. Hence `Theta(G)>=N^(1/k)`, proving the qualitative equivalence of unbounded Ramsey bases and unbounded capacities. This was checked on the explicit `K_16` coloring. A padding lemma records when subsequences suffice. More concretely, an effective-capacity criterion is proved: if for every large `t` some independence-two graph has a witness power `q_t<=t^D` with achieved base at least `t^a`, then taking multiples of `q_t` and `t≈k^(1/(D+1))` gives `R_k>=k^((a/(D+1)+o(1))k)` for every large `k`. Thus the missing capacity ingredient is polynomially controlled witness power plus polynomially growing achieved base. The criterion is sufficient but loses constants: feeding it an every-`t` coloring with witness `q_t=t` gives exponent `a/2`, whereas direct padding retains `a`.

Failed algebra shortcut: strong products do not obviously preserve a bounded independence number (`alpha(G boxtimes H)` can exceed the product of individual independence numbers), and Shannon capacity is only safely supermultiplicative here, not assumed multiplicative. Joins preserve `alpha<=2` but do not have a simple multiplicative capacity law. No graph-product shortcut is claimed.

## New route: missing-color blow-ups

A rigorous palette-reuse lemma is now in `proof_ramsey.md`: replace each outer vertex `x` by an inner coloring using only colors absent from all edges incident to `x`. Mixed triangles cannot be monochromatic. This yields

`R_k(3)-1 >= sum_x (R_|M_x|(3)-1)`

for every triangle-free outer `k`-coloring, where `M_x` is the missing-color set at `x`. A brute-force toy instance (a two-color `K_4` viewed in a three-color palette, blown into four `K_2` clusters) checked all 56 triangles. If the outer coloring is locally `s`-colored, this simplifies to `R_k-1 >= N(R_{k-s}-1)`.

Defining `L_s` as the largest order of a triangle-free locally `s`-colored complete graph gives the clean recurrence `L_s<=1+sL_(s-1)`: partition around a vertex; inside each incident-color class that color is forbidden, reducing local palette by one. Hence `L_s < 3s!`. Exact values: `L_1=2`, `L_2=5` (two complementary `C_5`s), and `L_3=16` (the explicit construction above meets the recurrence upper bound). A canonical exhaustive search independently found local-2 feasibility through `N=5` and none at `N=6`, agreeing with the proof. The factorial upper bound leaves conceptual room for `L_s^(1/s)` of order `s`, but says nothing about constructing such colorings with a controlled global palette. Equality is rigid: at every vertex all `s` incident classes must have size `L_(s-1)` and induce extremal local-`s-1` colorings. Every nonempty global color graph is then `L_(s-1)`-regular on support at least `2L_(s-1)`, so the number of global colors is at most `floor((1+sL_(s-1))s/(2L_(s-1)))`. Thus `L_4=65` would force four induced `K_16` extremizers around every vertex, 16-regular triangle-free color graphs, and at most eight global colors. Any color support of minimum size 32 would have to be exactly `K_(16,16)` by Mantel equality. If eight colors occur, the exact four-element vertex palettes form an intersecting family on `[8]`, hence at most 35 types. Also the eight support sizes are at least 32 and sum to 260, so at least four equal 32; their color graphs are forced `K_(16,16)`. Two edge-disjoint complete bipartite color classes cannot separate the same pair on their support overlap; a binary cut argument forces one restricted cut constant, hence their support intersection is at most 16. Random set systems show the resulting support-size/intersection constraints alone are feasible. Four minimum classes can be encoded as 65 words in `{0,1,star}^4`, each coordinate having counts `(16,16,33)`, with every coordinate-pair overlap constant in one bit. This is a concrete SAT/ILP target, but no infeasibility is proved. A linear-program feasibility scan over the 81 ternary word types and all pairwise cut-orientation choices found a feasible aggregate solution, so these aggregate constraints alone cannot contradict the eight-color case; finer edge/color constraints are essential. This equality-obstruction route is banked after the aggregate system proved feasible; no contradiction should be inferred from the necessary conditions.

Private-edge coloring gives a test case with `s=N-1` and global palette size `binom(N,2)`, but its iterated gain per lost inner color is `log N/(N-1)`, maximized at `N=2`; hence it adds no superexponential leverage.

A precise seed criterion is now proved: a triangle-free `K_N` using `g` colors globally and at most `s` locally yields `R_k-1>=N^(1+floor((k-g)/s))`. Thus seeds with `log N = Omega(s log s)` and `g=O(s^d)` imply `log R_k = Omega(k log k)` by taking `s` near `k^(1/d)`. This cleanly separates the two required resources: factorial local size and polynomial global palette.

Exploratory failed seed: on all `n!` permutations, color a pair by the unordered pair of symbols at their first differing coordinate. This is triangle-free, but every vertex sees all `binom(n,2)` colors. Hence `N=n!`, `s=g=binom(n,2)` and `log N/s -> 0`; it is useless asymptotically. The proof and exhaustive checks through `n=5` are banked in `proof_ramsey.md`.

A tempting compression—map each unordered symbol pair through a proper edge-coloring of `K_n`, reducing to `n` or `n-1` colors—fails. Explicit monochromatic triangles occur already for `n=4`; the issue is that the three original pair-labels in a permutation triangle need not form adjacent edges of one symbol triangle, so properness gives no protection. This route is now stalled after two variants (raw pair labels are too numerous; compressed labels break triangle-freeness).

Switched to a probabilistic palette-system formulation. If vertex palettes `P_i` have size at most `s`, pairwise intersections at least `q`, and global union size `g`, independent edge choices plus the symmetric local lemma work when `e(3N-8)g/q^3<=1`. The exact dependency degree `3(N-3)` was checked combinatorially for small `N`, and 10,000 random palette triples confirmed the event-probability inequality. Equal palettes recover only `N=Theta(s^2)`, far below factorial scale; the coarse LLL route is banked after this second nudge.

A composition lemma for local seeds is banked: `(N_1,g_1,s_1)` and `(N_2,g_2,s_2)` lexicographically compose to `(N_1N_2,g_1+g_2,s_1+s_2)`. Therefore products from any finite seed library have bounded `log N/s` and cannot supply the required improving family.

A partial-permutation tree has exactly `s! sum_(j=0)^s 1/j!` vertices, matching the numerical local upper-bound recurrence. First-difference unordered-pair coloring (with termination symbol) is triangle-free, but maximum local palette is `binom(s+1,2)`, attained at full lists. More strongly, its label set is compression-rigid: every two distinct labels occur as the only two labels on some triangle, so merging either pair creates a monochromatic triangle. A complete symbolic case proof is in `proof_ramsey.md`; all pair witnesses were programmatically validated for `s=6`. Thus no deterministic quotient reduces its palette. Truncating to lists of length at most `ell` gives exact order `sum_(j<=ell)(s)_j` and exact maximum local palette `ell(2s-ell+1)/2`. Uniformly, `log N/q=O(log s/s)`, so no truncation has unbounded per-local-color base. The formula was checked for `s<=8`. The route is now fully banked: neither quotienting nor depth truncation repairs it. Nor does a one-step missing-color blow-up with binary inner colorings: the full tree has global palette `g=binom(s+1,2)`, every vertex sees at least `s` colors, and fewer than `3s!` vertices, so total order is at most `3s!2^(g-s)` and log-order/global-color tends to `log 2`.

A local-palette set-system formulation is banked: incident palettes `P_v` are pairwise intersecting subsets of the global palette, each of size at most `s`. There are at most `2^(g-1)` distinct palette types by complement pairing. Multiplicity is not actually unbounded: one palette type `P` contains at most `R_|P|(3)-1` vertices. More sharply, `N<=min(2^(g-1),sum_(j<=s)binom(g,j))(R_s(3)-1)`. Layerwise Erdős--Ko--Rado improves the palette-type count in the sparse regime `s<=g/2` to `sum_(i=0)^(s-1)binom(g-1,i)`, though this changes constants rather than the exponent-level conclusion. Since the type count is at most `s(eg/s)^s`, a seed with `g=O(s^d)` and `N>=s^(c s)` already hides an ordinary bound about `s^((c-d+1)s)` whenever `c>d-1`. Thus local iteration only offers potentially different leverage in the complementary parameter range. The same argument distributionally bounds vertices of palette size at most `t` by `min(2^(g-1),sum_(j<=t)binom(g,j))(R_t-1)`; a large seed must therefore genuinely use many near-maximal local palettes. A clique-cover reformulation says color classes are triangle-free graphs partitioning `E(K_N)`, with each vertex nonisolated in at most `s` classes. Mantel plus incidence counting gives only a tautologically weak bound (`sum v_a<=Ns`, `binom(N,2)<=sum floor(v_a^2/4)`), so raw density counts cannot resolve the local-seed problem.

The permutation route has been reframed as a coding problem rather than revived blindly. For `F subset S_n`, define `D_pi` as the unordered symbol pairs exposed at first differences from `pi`. The standard coloring has local palette `max|D_pi|`. Need `|F|>=exp(Omega(s log s))` while `|D_pi|<=s`. Independent disjoint swaps give exactly `2^s`, so do not improve the baseline. An exact backtracking search for `n=4` found maximum family sizes `2,4,8` for local budgets `s=1,2,3`, again exactly `2^s`; this is evidence only, not a theorem for general `n`.

## Route assessment after re-refereeing

The fixed lexicographic-product route is banked and considered stalled: its parameter identity itself proves it cannot yield an unbounded base from any fixed seed. The explicit `K_16` construction was directly checked on all `binom(16,3)=560` triangles. Work has switched to the missing-color/palette-reuse route.

## Referee warning

Any proposal that reuses the same color in multiple coordinate roles must inspect triangles with two equal first coordinates and triangles whose three first coordinates are all distinct. Product-size parameter accounting must distinguish `R_k(3)>N` from `>=N`.
